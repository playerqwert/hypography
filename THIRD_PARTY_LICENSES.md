# Сторонние компоненты / Third-party components

Hypography использует чужие шрифты и библиотеки. Все они бесплатные, их лицензии разрешают так делать. Полные тексты лицензий шрифтов лежат в [`assets/fonts/licenses/`](assets/fonts/licenses/).

| Шрифт | Лицензия |

| Handjet | SIL Open Font License 1.1 |

| Dela Gothic One | SIL Open Font License 1.1 |
| Unbounded | SIL Open Font License 1.1 |
| Seymour One | SIL Open Font License 1.1 |
| Russo One | SIL Open Font License 1.1 |

| Roboto Slab | Apache License 2.0 |
| **Hypography Pixel** | SIL Open Font License 1.1. Это изменённая версия Press Start 2P: в ней перерисована буква «Й». У Press Start 2P есть зарезервированное имя (Reserved Font Name), поэтому изменённая версия называется иначе. Оригинал: © 2012 The Press Start 2P Project Authors. |

Шрифты встроены в программу в урезанном виде (оставлены латиница, кириллица и знаки).
