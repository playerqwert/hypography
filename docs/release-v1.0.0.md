Первая версия **Типографии хайпа**: программа сама верстает плакаты и мемы для голосования за 5ORKA на SLAY 2026.

### Какой файл качать
| | |
|---|---|
| **Hypography-portable.exe** | Windows: просто запусти, ничего не устанавливается (~40 МБ, открывается за 1–2 с) |
| **Hypography-setup.exe** | Windows: установщик с ярлыком в «Пуске» (~98 МБ) |
| **Hypography.apk** | Android (~30 МБ) |

Если Windows покажет «Windows защитила ваш компьютер», нажми **«Подробнее» → «Выполнить в любом случае»**: у программы нет платной цифровой подписи. На Android при установке разреши установку из этого источника.

### Что внутри
- 5 стилей: Фан-сектор, Ксерокс, Босс-файт, Розыск, Таблоид. У каждого несколько раскладок, кнопка «Ещё вариант» их перебирает.
- Ч/б для обычного принтера и экономный цветной режим.
- Плакаты по 1, 3 или 9 на лист A4, мемы по 6 или 12, с метками для резки.
- Очередь на печать, которая скачивается одним PDF.
- Своё фото с автоматическим вырезанием фона, работает офлайн.
- Тексты на RU, EN и PT: больше 150 готовых фраз или свой текст.
- Перетаскивание с привязками, выделение нескольких элементов, правка надписей двойным кликом.
- QR-код на голосование с проверкой, что он читается.

Работает без интернета.
